# Student Performance Data Analysis

This is a simple Python project for analyzing student performance data.

## Project Objective

The main objective of this project is to analyze student attendance and marks in Maths, Python, and DBMS using Python.

## Concepts Covered

- Variables and data types
- Lists and dictionaries
- Loops and functions
- CSV file handling
- Mean, median and mode
- Variance and standard deviation
- Correlation
- Basic data analysis

## Dataset

The dataset contains information about 10 students.

### Data Includes

- Student name
- Attendance percentage
- Maths marks
- Python marks
- DBMS marks

## Analysis

The Python program calculates:

- Average attendance
- Average Maths marks
- Average Python marks
- Average DBMS marks
- Median of Maths marks
- Mode of Maths marks
- Variance of Maths marks
- Standard deviation of Maths marks
- Correlation between attendance and average marks

## Python Concepts Used

- Variables
- Data types
- Lists
- Dictionaries
- Loops
- Functions
- CSV file handling
- Statistical calculations
